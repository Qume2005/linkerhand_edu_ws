# l10_hand_control_panel

L10 右手控制面板 —— 基于 PySide2 (Qt) 的图形化手势控制前端。

> 详见 [技术设计文档](REPORT.md)

## 概述

`l10_hand_control_panel` 提供了一个直观的 GUI 界面，用于控制 L10 右手的 10 个自由度。面板包含三种交互方式：

1. **双指示器滑块**: 精确控制每个 DOF 的目标值
2. **3D 骨架控件**: 直接拖拽指尖来调整手部姿态
3. **预设手势按钮**: 一键切换常用手势
4. **自定义手势**: 创建、编辑、删除自定义手势
5. **手势序列**: 创建、编辑、播放手势序列

此外，面板还实时显示触觉传感器数据 (5 指热力图) 和当前位姿状态。

## 双色滑块概念

每个 DOF 对应一个自定义的 `DualSlider` 控件，在同一个滑槽上显示两个菱形指示器：

```
  ┌────────────────────────────────────┐
  │         ◇ 灰色: 当前位姿 (只读)     │
  │  ◆ 白色: 目标位姿 (可拖动)          │
  └────────────────────────────────────┘
```

- **灰色菱形** (小): 显示从网关订阅的 `/l10_gateway/current/dof`，反映后端的实际位姿
- **白色菱形** (大): 显示用户设置的目标值，可通过鼠标拖动改变

当用户拖动白色菱形时，新的目标值会发布到 `/l10_gateway/cmd/dof`。

## 触觉热力图

底部 `TactileStripWidget` 显示 5 个手指的触觉传感器数据：

- 每个手指对应一个 12×6 压力矩阵
- 使用 **plasma 色表** (4 段渐变) 进行可视化:
  - 深蓝 (0) → 紫色 (85) → 粉红 (170) → 亮黄 (255)
- 下方显示总压力质量 (克)
- 左侧附带垂直色标条作为参考

数据来自网关透传的触觉传感器信息 (`/l10_gateway/sensor/matrix_touch` 和 `matrix_touch_mass`)。

## 3D 骨架控件

右侧的 `HandModelWidget` 使用 MuJoCo 离屏渲染技术，显示可交互的 3D 手部模型：

### 渲染管线

```
DOF 值 (0-255) → 弧度转换 → 20 关节 MuJoCo qpos → mj_forward() → 离屏渲染 → QImage → Qt 绘制
```

### 指尖拖拽 IK

5 个指尖用彩色圆圈标记为控制点:
- 拇指 (红)、食指 (绿)、中指 (蓝)、无名指 (黄)、小指 (紫)

拖拽控制点时，系统在**屏幕空间**执行 IK 求解:
1. **网格采样**: 在 DOF 弧度空间中均匀采样 (2-DOF 约 100 点, 3-DOF 约 216 点)
2. **Jacobian 精化**: 从最优起点出发，使用阻尼最小二乘法迭代精化
3. **轨迹预测**: 利用历史鼠标速度预测下一帧位置，减少延迟感

### 相机控制

- 右键拖拽: 旋转视角 (轴锁定，水平或垂直)
- 滚轮: 缩放距离
- 相机状态通过网关同步到其他控件

## Qt + ROS 线程模型

面板涉及两个线程的协作:

```
┌─────────────────────────────┐     ┌────────────────────────────┐
│  Qt 主线程                    │     │  ROS spin daemon 线程       │
│                              │     │                            │
│  • UI 渲染 (paintEvent)      │     │  rclpy.spin_once() 循环    │
│  • 用户交互 (鼠标/键盘)       │     │  • 接收 /l10_gateway/* 消息 │
│  • 定时器 (30 FPS 渲染)      │     │  • 触发回调函数             │
│                              │     │                            │
│         ◄── Signal/Slot ──  │     │  ── emit() ──►             │
│             (线程安全)        │     │      _StateSignal          │
└─────────────────────────────┘     └────────────────────────────┘
```

**关键点**: Qt 的 GUI 操作必须在主线程中执行。ROS 回调在 daemon 线程中运行，通过 `_StateSignal` 的 Signal 机制将数据安全传递到主线程。

## `_syncing` 标志防循环机制

面板的滑块、骨架控件和 ROS 通信形成了一个三角形关系。当外部命令 (如 LLM 控制器) 更新目标状态时，面板需要同步更新滑块和骨架位置。但这种更新会触发 `valueChanged` 信号，导致重新发布命令，形成死循环。

`_syncing` 标志的解决方式:

```
外部命令到达
    │
    ▼
_syncing = True    ← 设置标志
    │
    ├─ 更新滑块位置 (valueChanged 被触发但被 _syncing 阻止)
    ├─ 更新骨架位置
    │
    ▼
_syncing = False   ← 恢复标志
```

在 `_on_slider`、`_on_skeleton_drag`、`_apply_target_state` 等回调中，如果 `_syncing` 为 True，则立即返回，不发布命令。

## 自定义手势

面板支持创建自定义手势，将任意 DOF 配置保存为可复用的手势名称。

### 创建手势

1. 在控制面板的「手势管理」区域，切换到「自定义」标签页
2. 点击「新建手势」按钮
3. 在弹出的对话框中：
   - 输入手势名称（不可与预设手势重名）
   - 可选输入描述
   - 通过 10 个 DOF 滑块调整目标值
   - 使用「从当前滑块导入」快速复制当前滑块位置
   - 使用「重置为张开」将滑块归位到 255
4. 点击「保存」

### 编辑/删除手势

- **编辑**: 在自定义手势按钮上右键 →「编辑」，修改后保存
- **删除**: 在自定义手势按钮上右键 →「删除」

### 数据存储

自定义手势保存在 `~/.config/l10_hand_control_panel/gestures.json`（Linux），格式：

```json
{
  "version": "1.0",
  "custom_gestures": {
    "我的手势": {
      "dof_values": [255, 255, 200, 200, 200, 200, 100, 100, 100, 255],
      "description": "自定义描述",
      "created_at": "2025-01-01T00:00:00",
      "updated_at": "2025-01-01T00:00:00"
    }
  }
}
```

## 手势序列

面板支持创建手势序列，将多个手势按顺序编排并自动播放。

### 创建序列

1. 在「手势管理」区域，切换到「序列」标签页
2. 点击「新建序列」按钮
3. 在弹出的对话框中：
   - 输入序列名称
   - 勾选「循环播放」可选
   - 添加步骤：选择手势 → 设置持续时间 → 设置步骤间延迟
   - 使用 ↑↓ 按钮调整步骤顺序
   - 点击 ✕ 删除不需要的步骤
4. 点击「保存」

### 播放/停止序列

- **播放**: 在序列列表中点击 ▶ 按钮
- **停止**: 播放时点击「⏹ 停止」按钮
- 播放期间序列按钮自动禁用，停止后恢复

### 序列步骤格式

```json
{
  "name": "打招呼",
  "loop": false,
  "steps": [
    {"gesture_name": "open", "duration": 1.0, "delay_after": 0.0},
    {"gesture_name": "fist", "duration": 0.5, "delay_after": 0.3},
    {"gesture_name": "open", "duration": 1.5, "delay_after": 0.0}
  ]
}
```

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `gesture_name` | 手势名称（预设或自定义） | — |
| `duration` | 保持该手势的持续时间 (秒) | 1.0 |
| `delay_after` | 步骤间延迟 (秒)，延迟期间保持当前 DOF | 0.0 |
| `loop` | 是否循环播放 | false |

### 播放算法

序列播放使用状态机驱动，30Hz 更新频率：

```
状态: {steps[], current_step, phase("duration"|"delay"), phase_start}

每一步:
  1. duration 阶段: 保持手势 duration 秒 → 应用 DOF
  2. delay 阶段: 等待 delay_after 秒 → 保持当前 DOF
  3. 推进到下一步
  4. 最后一步: loop=true 则回到第 1 步，否则停止
```

### 数据存储

序列数据同样保存在 `gestures.json` 中：

```json
{
  "sequences": {
    "打招呼": {
      "steps": [...],
      "loop": false,
      "created_at": "...",
      "updated_at": "..."
    }
  }
}
```

## 线程安全

- 序列播放在 Qt 主线程运行，通过 QTimer (30Hz) 驱动
- `_syncing` 防循环机制在序列播放期间自动生效，避免与 ROS 回调冲突
